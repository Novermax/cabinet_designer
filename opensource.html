What this page is

Cabinet Designer is proprietary software, and it is distributed together with free and open-source components. Each of those components is licensed to you under its own terms, not under the Cabinet Designer licence agreement. Nothing in that agreement limits, restricts or overrides any right those licences grant you.

The complete list of components, with the version and licence of each, is installed with the product and is also shown inside the application under Help → Version → Third-party licences.

The two main components

  • FreeCAD — the parametric geometry engine, used under the GNU Lesser General Public License (LGPL). It is shipped unmodified and can be replaced with your own build; the installed product includes instructions for doing so.
  • Blender — the Cycles render engine, used under the GNU General Public License (GPL). It is shipped unmodified and runs as a separate program. The scripts we wrote that run inside it are GPL too, and ship as readable source with the product.

Source code for open-source components

A source package is published for each release. It contains the source of the copyleft components at the exact versions that release was built against, our own GPL-licensed render scripts, and the full licence texts.

  • 4.3.3 — cabinet-designer-oss-sources-4.3.3.zip (159 MB)

If a link is missing or does not work, write to cabinetdesigner.global@gmail.com and we will send you the package.

Written offer

For components licensed under the GPL or the LGPL whose source is not practical to bundle, a written offer valid for at least three years accompanies the product. It is included in the source package as WRITTEN_OFFER.txt.
