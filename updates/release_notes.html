Cabinet Designer 4.9.0

2026-09-24

Doors with a fixed panel: a compartment can now be closed by a row of fronts written as a formula (f300/*/*), where the "f" prefix marks a fixed panel that does not open.

The door next to a fixed panel is hinged directly on the back of the panel, with no upright, no frame and no batten; the fixed panel is held by dowels into the top, the bottom and the side beside it.

Two neighbouring doors open as a book or as a bifold, switchable from the door menu.

Separate hinge choices for the fixed-panel mount and for the between-doors mount, with all the holes of a front kept on a single line.

In a row of fronts the hinge baseplate pins are no longer drawn in the 3-D view, as on a double door; the drilling is unchanged.

Cabinet Designer 4.4.2

2026-09-15

Revised the system of quoted designs for diagonal-cut corner unit

Fixed: on some Windows PCs the update download failed with a certificate error (CERTIFICATE_VERIFY_FAILED), even though the new version was found and its release notes were shown correctly.

The cause was outside the application: Windows ships a reduced list of trusted certificate authorities and completes it only when a browser needs one, which had never happened on those PCs.

Cabinet Designer now carries its own up-to-date list and uses it alongside the one Windows provides, on every connection it makes: updates, release notes, licence activation and usage statistics.

CNC generation no longer asks which machine to produce for: the "Machine code format" of the technology configuration decides, and it now offers DXF and IR files only beside XCS and PGMX. The Multi-Module app follows the same setting, so its Machine selector is gone; the free "Default machine" field has been removed as well.

Cabinet Designer 4.3.3

Open-source licence compliance. The installer no longer carries build tools it

never runs (PyArmor, Nuitka) nor the FEM and graph programs the application

never calls (CalculiX, Gmsh, Graphviz): the download is 214 MB smaller, and the

build now stops if an unexpected package turns up in the bundled runtime.

open-source component with its version, its licence and the full licence text.

It works in the Demo too. FreeCAD and Blender are credited there and on the

website.

installer, as the GPL and the LGPL require.

You can now run the application against your own build of FreeCAD, through the

CABINET_FREECAD_DIR environment variable.

Photorealistic rendering: fixed the floor going transparent in the foreground

and showing the backdrop through it, and the camera no longer leaves the room

when you zoom out.

Licence agreement updated to version 1.3: a new section on third-party and

open-source components, and the reverse-engineering restriction no longer

overrides rights granted by an open-source licence (acceptance is requested

again).
